<task type="auto">
  <name>Task 3: Clean git history of exposed secrets</name>
  <files></files>
  <action>
Use git-filter-repo to remove any API keys from git history.

1. First, check if git-filter-repo is installed:
```bash
git filter-repo --version || pip install git-filter-repo
```

2. Create expressions file for secret patterns:
```bash
cat > /tmp/expressions.txt << 'EOF'
***REMOVED_GROQ_KEY***==>***REMOVED_GROQ_KEY***
EOF
```

3. Run git-filter-repo (from repo root):
```bash
cd "$(git rev-parse --show-toplevel)"
git filter-repo --sensitive-data-removal --replace-text /tmp/expressions.txt --force
```

Note: --force is needed because this is not a fresh clone.

4. Clean up:
```bash
rm /tmp/expressions.txt
```

This rewrites history, replacing any Groq API keys with `***REMOVED_GROQ_KEY***`.
  </action>
  <verify>
1. Check history was rewritten: `git log --oneline -5` (should show rewritten commits)
2. Search for leaked keys: `git log -p --all -S "gsk_" | head -20` (should find nothing or only REMOVED text)
  </verify>
  <done>Git history no longer contains Groq API key patterns</done>
</task>
