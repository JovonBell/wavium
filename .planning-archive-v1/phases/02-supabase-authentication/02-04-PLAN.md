<task type="auto">
  <name>Task 3: Add authenticated user info endpoint</name>
  <files>backend/main.py</files>
  <action>
Add a new endpoint for the frontend to verify authentication and get user info.

Add this response model after existing models:
```python
class UserInfoResponse(BaseModel):
    user_id: str
    email: str | None = None
```

Add this endpoint after the existing endpoints (before `if __name__`):
```python
@app.get("/api/me", response_model=UserInfoResponse)
async def api_get_me(
    user: dict = Depends(get_current_user),
):
    """
    Get current authenticated user info.

    Returns user ID and email from JWT claims.
    Useful for frontend to verify authentication status.
    """
    return UserInfoResponse(
        user_id=user["sub"],
        email=user.get("email"),
    )
```

This endpoint:
- Uses `get_current_user` (returns full payload, not just ID)
- Returns user_id (sub claim) and email
- Useful for frontend to verify backend accepts their token
