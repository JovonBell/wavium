  <action>
Update config.py to use Python's tempfile module for cross-platform temp directory:

1. Add import at top:
```python
import tempfile
```

2. Change AUDIO_TEMP_DIR from:
```python
AUDIO_TEMP_DIR: str = "/tmp/wavium"
```
To:
```python

    default_factory=lambda: str(Path(tempfile.gettempdir()) / "wavium"),
```

```python
from pathlib import Path
```

This ensures:

- macOS: /var/folders/.../wavium or /tmp/wavium
- Linux: /tmp/wavium
