## Goal

Refactor GlassmorphicCard to deliver real glassmorphism with three distinct visual layers, ambient glow shadows, and Android blur fallback.

## Tasks

### Task 1: Add Android blur fallback and top-edge highlight

**File:** `wavium/src/components/ui/GlassmorphicCard.tsx`

**Changes:**

1. Import `Platform` from react-native and `LinearGradient` from expo-linear-gradient
2. Add Android blur fallback: when `Platform.OS === 'android' && Platform.Version !== undefined && Platform.Version < 31`, render a semi-transparent View with `colors.glassOverlay` at 0.85 opacity instead of BlurView
3. Add `experimentalBlurMethod="dimezisBlurView"` prop to BlurView for Android API 31+
4. Add Layer 3 — top-edge highlight: absolute-positioned LinearGradient at top of card content, height 1px, colors `['transparent', colors.glassBorder, 'transparent']`, horizontal direction
5. Update the overlay (Layer 2) to use `colors.glassOverlay` instead of `colors.surfaceGlow`
6. Always apply ambient glow shadow (SURF-02): remove the `borderGlow &&` conditional, always apply shadow with `shadowColor: colors.primaryGradient[0]`, `shadowOpacity: 0.15`, `shadowRadius: 16`
7. Update border color to always use `colors.glassBorder` for the glass edge effect
8. Keep blur `intensity` as a static prop (PERF-03 — never animate blur intensity)

**Verification:**
- Card renders 3 visible depth layers: blur background, tinted overlay, top-edge highlight
- Ambient glow visible on all cards without needing `borderGlow` prop
- On Android pre-31: fallback renders without crash (semi-transparent overlay)
- BlurView intensity is never animated (PERF-03)
