# Plan 02-02: HapticButton Gradient CTA + Micro-interactions

**Requirements:** INTR-01, INTR-02, INTR-03, INTR-04
**Wave:** 1
**Files:** `wavium/src/components/ui/HapticButton.tsx`

## Goal

Transform primary CTA buttons to use gold gradient fill with breathing glow animation, and ensure all touch targets have consistent micro-interaction behavior.

## Tasks

### Task 1: Primary variant gold gradient fill + breathing glow

**File:** `wavium/src/components/ui/HapticButton.tsx`

**Changes:**

1. Import `LinearGradient` from expo-linear-gradient
2. Import `withRepeat`, `withTiming`, `Easing`, `interpolate` from reanimated (some already imported)
3. For `primary` variant: wrap button content in a LinearGradient using `colors.primaryGradient` as the color array, start `{x: 0, y: 0}`, end `{x: 1, y: 0}` (horizontal gradient)
4. Add breathing glow animation: create a `glowOpacity` SharedValue that pulses between 0.15 and 0.4 using `withRepeat(withTiming(..., {duration: 2000, easing: Easing.inOut(Easing.sin)}), -1, true)`. Start animation on mount for primary variant.
5. Apply animated shadow using `useAnimatedStyle` — `shadowColor: colors.primaryGradient[1]`, `shadowRadius: 20`, `shadowOpacity: glowOpacity`. This creates the breathing glow effect.
6. For `secondary` variant (INTR-02): use gradient border technique — outer View with LinearGradient background + 1px padding, inner View with `colors.background` background. Pulse the gradient opacity subtly.
7. Update scale from 0.95 to 0.96 (INTR-03)
8. Ensure minimum height is enforced: add `minHeight: 44` to button base styles (INTR-03 touch target)
9. Update text style to use `fontFamily: fontFamilies.bodyMedium` from typography (currently uses `fontWeight: '600'`)

**Verification:**
- Primary buttons show horizontal gold gradient fill
- A visible breathing glow pulses at rest (no interaction needed)
- Secondary buttons show gradient border
- Tap produces scale-to-0.96 + spring release
- All buttons meet 44px minimum touch target
