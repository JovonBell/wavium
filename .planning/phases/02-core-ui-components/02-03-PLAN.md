**Files:** Multiple UI components

**Changes:**

1. Audit all component files for hardcoded spacing values not using tokens

3. Key fixes:

   - TabBar: `marginTop: 4` → `spacing.xs`
   - GlassmorphicCard: padding system already uses tokens (good)
   - HapticButton: icon `marginRight` already uses `spacing.xs`

**Verification:**
- Cards: all GlassmorphicCard instances show 20px corners
- Chips: example chips show 12px corners (or pill if design intent is pill)
- CTAs: HapticButton primary/secondary show pill-shaped corners
- No hardcoded spacing values in UI component files
