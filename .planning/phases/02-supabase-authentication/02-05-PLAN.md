Configure Supabase project and add credentials to environment files.

**Step 1: Create or access Supabase project**
1. Go to https://supabase.com/dashboard
2. Create new project (or use existing)
3. Wait for project to initialize (takes ~2 minutes)

**Step 2: Get API credentials**
1. Go to Project Settings -> API
2. Copy "Project URL" (e.g., https://abc123.supabase.co)
3. Copy "anon public" key (starts with eyJ...)

**Step 3: Configure redirect URLs**
1. Go to Authentication -> URL Configuration
2. Under "Redirect URLs", add:
   - `wavium://auth-callback`
   - `wavium://reset-password`
   - `wavium://**` (wildcard for development)
3. Save changes

**Step 4: Create frontend .env**

```bash
cd wavium

# EXPO_PUBLIC_SUPABASE_URL=your-project-url

```

**Step 5: Update backend .env**
```bash
cd backend
# Edit .env and add:
```

**Step 6: Verify backend starts**

```bash
cd backend && python -m uvicorn main:app --reload
```

Should start without errors.

**Step 7: Verify frontend starts**

<task type="checkpoint:human-verify" gate="blocking">
  <what-built>End-to-end authentication flow</what-built>
  <how-to-verify>
**Test the complete auth flow:**

1. **Start both servers:**
   - Backend: `cd backend && python -m uvicorn main:app --reload` (port 8000)
   - Frontend: `cd wavium && npx expo start`

2. **Test backend JWT rejection (unauthenticated):**
   ```bash
   curl -X POST http://localhost:8000/api/generate-affirmations \
     -H "Content-Type: application/json" \
     -d '{"intention": "test"}'
   ```
   Should return 401 Unauthorized with "Bearer authentication required".

3. **Test backend public endpoints:**
   ```bash
   curl http://localhost:8000/health
   curl http://localhost:8000/api/voices
   ```
   Should return 200 OK (no auth required).

4. **Create test user in Supabase:**
   - Go to Supabase Dashboard -> Authentication -> Users
   - Click "Add user" -> "Create new user"
   - Enter email and password
   - Note: For testing, you can disable email confirmation in Auth -> Settings

5. **Get test JWT token:**
   - In Supabase Dashboard, go to SQL Editor
   - Run this query to get a test token:
   ```sql
   SELECT auth.uid(), auth.jwt();
   ```
   - Or use the frontend to sign in and capture the token from session

6. **Test backend with valid JWT:**
   ```bash
   curl -X POST http://localhost:8000/api/generate-affirmations \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     -d '{"intention": "feeling confident"}'
   ```
   Should return 200 OK with generated affirmations.

7. **Test /api/me endpoint:**
   ```bash
   curl http://localhost:8000/api/me \
     -H "Authorization: Bearer YOUR_JWT_TOKEN"
   ```
   Should return user_id and email.

**Expected results:**
- Unauthenticated requests to protected endpoints return 401
- Public endpoints work without auth
- Valid JWT allows access to protected endpoints
- /api/me returns authenticated user info
  </how-to-verify>
  <resume-signal>Type "auth verified" when all tests pass, or describe any issues encountered</resume-signal>
