Create get_user_streak function (20260202000004_create_streak_function.sql):
- Takes p_user_id UUID parameter
- Returns table with: current_streak INTEGER, longest_streak INTEGER, last_session_date DATE
- Uses CTE pattern:
  1. session_dates: SELECT DISTINCT date_trunc('day', started_at)::date WHERE completed = true
  2. grouped: Assign streak groups using row_number trick (session_date - row_number gives same value for consecutive dates)
  3. streak_lengths: GROUP BY grp, count as streak_length
- current_streak: streak that includes today or yesterday (streak_end >= current_date - 1)
- longest_streak: max(streak_length)
- Use SECURITY DEFINER
- GRANT EXECUTE to authenticated role

Create add_session_xp function (20260202000005_create_xp_function.sql):
- Takes p_user_id UUID, p_xp INTEGER, p_minutes INTEGER
- Updates mindi_state atomically:
  - xp = xp + p_xp
  - total_sessions = total_sessions + 1
  - total_minutes = total_minutes + p_minutes
  - glow_level = CASE based on total XP thresholds (1000=5, 500=4, 200=3, 50=2, else 1)
  - updated_at = now()
- Use SECURITY DEFINER
- GRANT EXECUTE to authenticated role
