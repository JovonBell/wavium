## Goal

Create the useLoop hook for safe repeating animations with cleanup, and refactor VoidContainer's audioLevel from useState to useSharedValue to eliminate re-renders during audio playback.

## Tasks

### Task 1: Create useLoop hook (MIND-06)

**File:** `wavium/src/hooks/useLoop.ts` (NEW)

Create a hook that wraps `withRepeat(withTiming(...))` with proper `cancelAnimation()` cleanup:

```typescript
import { useEffect } from 'react';
import { useSharedValue, withRepeat, withTiming, cancelAnimation, Easing, SharedValue } from 'react-native-reanimated';

interface UseLoopOptions {
  from?: number;
  to?: number;
  duration?: number;
  easing?: (value: number) => number;
  autoStart?: boolean;
}

export function useLoop(options: UseLoopOptions = {}): SharedValue<number> {
  const {
    from = 0,
    to = 1,
    duration = 2000,
    easing = Easing.inOut(Easing.sin),
    autoStart = true,
  } = options;

  const value = useSharedValue(from);

  useEffect(() => {
    if (autoStart) {
      value.value = withRepeat(
        withTiming(to, { duration, easing }),
        -1,
        true
      );
    }
    return () => {
      cancelAnimation(value);
    };
  }, [autoStart, to, duration]);

  return value;
}
```

### Task 2: Refactor VoidContainer audioLevel (MIND-05)

**File:** `wavium/src/components/void/VoidContainer.tsx`

1. Replace `const [audioLevel, setAudioLevel] = useState(0)` with `const audioLevel = useSharedValue(0)`
2. Import `useSharedValue` from reanimated (already imported from the import block)
3. Update the polling interval: change `setAudioLevel(0.3 + Math.random() * 0.4)` to `audioLevel.value = 0.3 + Math.random() * 0.4` (runs on JS thread, writes to SharedValue — children read on UI thread, no re-render)
4. Update `setAudioLevel(0)` to `audioLevel.value = 0` when not playing
5. Update all child component props from `audioLevel={audioLevel}` to `audioLevel={audioLevel}` (same prop name, but now passing SharedValue)
6. Update `VoidContainerProps` — audioLevel is now internal, no interface change needed

### Task 3: Update child components to accept SharedValue

**Files:** Multiple components

Each component that receives `audioLevel` needs its prop type changed from `number` to `SharedValue<number>`, and any usage in `useAnimatedStyle` updated to read `.value`:

1. **MindiRenderer.tsx:** Change `audioLevel?: number` to `audioLevel?: SharedValue<number>`. In animatedStyle, change `audioLevel * 0.05` to `(audioLevel?.value ?? 0) * 0.05`. Also pass SharedValue through to MindiGlow.

2. **MindiGlow.tsx:** Change `audioLevel?: number` to `audioLevel?: SharedValue<number>`. In `useAnimatedStyle`, read `audioLevel?.value ?? 0`. In the JSX render, for static Skia opacity props that read audioLevel, use `useDerivedValue` to create a derived Skia-compatible value.

3. **StarField.tsx:** Change `audioLevel: number` to `audioLevel: SharedValue<number>`. Read `.value` in animated styles.

4. **NebulaRenderer.tsx:** Change `audioLevel: number` to `audioLevel: SharedValue<number>`. Read `.value` in animated styles.

5. **AffirmationSpirals.tsx:** Change `audioLevel: number` to `audioLevel: SharedValue<number>`. Read `.value` in animated styles.

**IMPORTANT:** When reading SharedValue in JSX render (not in useAnimatedStyle or useDerivedValue), you CANNOT read `.value` directly — it won't react. For Skia props that need the value, use `useDerivedValue(() => audioLevel.value)` from reanimated.
