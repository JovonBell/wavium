# Plan 03-02: Mindi Breathing + Glow Audio Sync

**Requirements:** MIND-01, MIND-02, PERF-02
**Wave:** 1
**Files:** `wavium/src/components/mindi/MindiRenderer.tsx`, `wavium/src/components/mindi/MindiGlow.tsx`

## Goal

Add visible idle breathing animation to Mindi and sync glow intensity with audio playback level, using SharedValues and Skia interpolateColors where applicable.

## Tasks

### Task 1: Add idle breathing animation (MIND-01)

**File:** `wavium/src/components/mindi/MindiRenderer.tsx`

1. Add a dedicated `breathScale` SharedValue for the breathing pulse
2. In the idle/default state useEffect, start breathing: `breathScale.value = withRepeat(withTiming(1.02, {duration: 2000, easing: Easing.inOut(Easing.sin)}), -1, true)` starting from 1.0
3. In non-idle states (generating, excited), cancel breathing or override with state-specific scale
4. Include `breathScale` in the animatedStyle transform: multiply with `scale.value`
5. Add proper `cancelAnimation(breathScale)` in cleanup
6. The breathing should be a slow, visible 1.0 → 1.02 pulse over ~4 seconds (2s up, 2s down)

### Task 2: Sync glow with audio (MIND-02)

**File:** `wavium/src/components/mindi/MindiGlow.tsx`

1. After Plan 03-01 runs, `audioLevel` will be `SharedValue<number>`
2. Update the `useAnimatedStyle` to make glow intensity proportional to audioLevel:
   - When audioLevel > 0 (playing): scale increases, opacity increases
   - The glow should pulse MORE intensely when audio is active
3. In the animatedStyle:
   ```
   const audioVal = audioLevel?.value ?? 0;
   const scale = interpolate(pulseAnim.value, [0, 1], [1, 1 + (intensity * 0.1) + (audioVal * 0.2)]);
   const opacityMod = interpolate(pulseAnim.value, [0, 1], [0.7 + audioVal * 0.15, 1]);
   ```
4. The connection between sound and glow should be perceptible — not subtle

### Task 3: Skia interpolateColors (PERF-02)

**File:** `wavium/src/components/mindi/MindiGlow.tsx`

Currently the Skia Circle opacity is set as a static prop with `audioLevel` addition. If any color interpolation is needed for glow color shifts during audio:

1. Import `interpolateColors` from `@shopify/react-native-skia` (NOT `interpolateColor` from reanimated)
2. If glow colors need to shift (e.g., warmer during high audio), use:
   ```
   const glowColor = useDerivedValue(() => {
     return interpolateColors(audioLevel.value, [0, 1], [baseColor, warmColor]);
   });
   ```
3. If no dynamic color interpolation is needed in this component, the requirement is satisfied by NOT using reanimated's interpolateColor for Skia props (which is already the case)

**Note:** PERF-02 may be more about prevention than adding new interpolation. The key rule is: never pass reanimated's interpolateColor output to Skia color props. If NebulaRenderer or TimeShiftingBackground need color animation in the future, they must use Skia's interpolateColors.

## Acceptance Criteria

- [ ] Mindi visibly breathes (1.0→1.02 scale pulse, ~4s) at idle (MIND-01)
- [ ] Glow intensity and scale increase during audio playback (MIND-02)
- [ ] No reanimated interpolateColor used for Skia color props (PERF-02)
