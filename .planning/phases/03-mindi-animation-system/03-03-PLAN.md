# Plan 03-03: Eye Tracking + Entrance Animations

**Requirements:** MIND-03, MIND-04
**Wave:** 2 (depends on 03-01 for SharedValue infrastructure)
**Files:** `wavium/src/components/mindi/MindiEyes.tsx`, `wavium/src/components/mindi/MindiRenderer.tsx`

## Goal

Make Mindi's eyes track touch position on screen and add entrance animations when Mindi appears on each screen.

## Tasks

### Task 1: Eye touch tracking (MIND-03)

**File:** `wavium/src/components/mindi/MindiEyes.tsx`

1. Add new props: `touchX?: SharedValue<number>`, `touchY?: SharedValue<number>` — these are screen-space touch coordinates
2. Add a `useDerivedValue` that computes pupil offset based on touch position relative to eye center:
   ```
   const derivedPupilX = useDerivedValue(() => {
     if (!touchX || !touchY) return 0;
     const dx = touchX.value - eyeProps.leftX;
     const maxOffset = eyeProps.pupilRadius * 0.5;
     return Math.max(-maxOffset, Math.min(maxOffset, dx * 0.02));
   });
   ```
3. Apply `derivedPupilX` and `derivedPupilY` as offsets to pupil Circle `cx`/`cy` props in the Skia canvas
4. Since these are Skia props, use `useDerivedValue` from reanimated (Skia can consume SharedValues as animated props)
5. Keep the existing state-driven `pupilX`/`pupilY` as fallback when touch is not active

**File:** `wavium/src/components/mindi/MindiRenderer.tsx`

1. Add `touchX` and `touchY` SharedValues (or accept them as props from parent)
2. Add a `onTouchMove` handler on the container View that updates `touchX.value` and `touchY.value`
3. Pass `touchX` and `touchY` to MindiEyes

**Note:** For VoidContainer, the touch tracking can use the same tap area or a separate gesture handler. The simplest approach is to add onTouchMove to MindiRenderer's container and let it track locally.

### Task 2: Entrance animations (MIND-04)

**File:** `wavium/src/components/mindi/MindiRenderer.tsx`

1. Add entrance animation on mount: Mindi translates up from below and scales from 0.5 to 1.0
2. Use Reanimated's entering layout animation: `FadeInDown` or a custom spring entrance
3. Add new prop `entrance?: 'slideUp' | 'fadeScale' | 'none'` defaulting to `'fadeScale'`
4. For `fadeScale`: On mount, animate:
   - `translateY: 30 → 0` with spring
   - `scale: 0.5 → 1.0` with spring (bouncy config)
   - `opacity: 0 → 1` with timing
5. Use `useEffect` on mount to trigger the entrance sequence
6. Different screens can pass different entrance types if needed

## Acceptance Criteria

- [ ] Eyes track touch/finger position on screen (MIND-03)
- [ ] Mindi animates into view with translate + scale entrance on each screen (MIND-04)
